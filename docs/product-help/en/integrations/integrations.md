# Connect integrations

Integrations are the tools agents may call. Connected apps, the marketplace and MCP servers live under Settings.

## Connected tools

The Connected page lists what this workspace already uses. Disconnect there when a tool should stop. Kind filters (inbox, MCP, and others) keep the list short.

## Marketplace

Marketplace is where you install a new app. Pick a kind, then connect with OAuth or the provider’s setup. Inbox-kind apps add channels; MCP-kind apps add tools for agents.

## MCP servers

MCP is how agents call external tools over a standard protocol. Add a server, test it, then decide in Govern whether agents may call it automatically or must ask.

## What to do next

Install one tool you already use, then set its allowance on Govern so agents cannot surprise you.

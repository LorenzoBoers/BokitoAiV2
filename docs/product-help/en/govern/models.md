# Choose models

Providers and models live under Settings. Operators choose what the workspace may call. Spend still shows on Cockpit Usage.

## Workspace models

Enable the chat and embedding models this workspace needs. Agents inherit a default; you can override the model on an agent card.

## Your own keys

You can add an Anthropic, OpenAI or OpenAI-compatible provider with your own key. Test the connection before you rely on it. When no key is set, the workspace uses the platform catalog if it is enabled.

## Spend and posture

Token budgets sit on projects and the workspace. Govern still decides whether an agent may act. A more capable model does not bypass approval.

## What to do next

Confirm a chat model is enabled, then open an agent and check which model it uses.

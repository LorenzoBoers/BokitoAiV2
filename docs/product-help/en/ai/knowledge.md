# How Knowledge works

Persona, memory, skills and checklists live as workspace docs. Agents read them on every run and can write back what they learn.

## Pick the right kind

Persona is tone and rules. Memory is long-term facts. Skills are procedures (SKILL.md style). Heartbeat and daily log are AI-maintained checklists.

## Publish for customers

Mark a doc published to expose it on the public help center for this tenant. Internal drafts stay in the workspace only. That help center is for your customers, not for Bokito product help.

## Search and write

Search is hybrid (keywords plus embeddings). Agents use the same docs through tools. Edits you make here are live on the next run.

## What to do next

Fill company.md during setup, then add a skill for a procedure you repeat. Chat with your assistant if you want it to draft the first version.

# How Agents works

Create and configure the AI workers for this workspace. Chat with them, give them tools, and point them at projects.

## Browse the library

Leads (product owners) sit above workers. Each card opens the agent so you can change instructions, model, tools and chat access.

## Chat and schedule

Chat opens an internal thread with that agent. Schedule jumps to Agenda filtered to the same agent so you can attach a wake.

## Add an agent

Admins add agents from New agent. Members talk to existing agents from Communication. Tool access and autonomy still follow Govern.

## What to do next

Brief the agent in Knowledge (persona, memory, skills), then set how autonomous it may be on Govern.

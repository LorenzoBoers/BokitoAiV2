# Install the website widget

The website widget is a small script on your site. Visitors chat with your assistant. Those conversations appear in Communication next to email.

## Install

Open the widget install page and copy the embed snippet onto your site. The snippet is scoped to this workspace. Branding (color, logo) follows workspace branding.

## Voice and hours

Set when the widget is available and how the assistant should sound for visitors. After hours you can point people to leave a message instead of expecting a live reply.

## Appearance

Choose the look of the launcher and panel. Keep it close to your site so visitors trust the chat.

## Help articles

If you publish Knowledge docs to the public help center, the widget can show a Help tab and related-article links. That is your customer help, not Bokito product help.

## What to do next

Install the snippet on a staging page first, send a test message, then confirm the thread appears in Communication.

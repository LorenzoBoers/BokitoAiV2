# Work agent runs

Agent runs are internal work: a scheduled sweep, a follow-up, a decision waiting on you. They stay out of Open so customer mail does not compete with background jobs.

## Open the runs list

![Agent runs list](/api/docs/assets/agent-runs/runs-list.png)
*Scheduled work stays out of Open.*

1. In Communication, switch the sidebar to **Agents**, then open **Agent runs**. Customer mail stays under **Customer**.
2. Use the chips **All**, **Updates**, **Results** and **Decisions**. **Updates** is in-progress work. **Results** is finished runs. Start on **Decisions** when something is waiting on you.
3. Cockpit **Awaiting decision** opens that same **Decisions** list. A paused agent will not finish a wake until you resume it on [Agents](/docs/ai/agents).

## Open a run and decide

1. Select a run to read what the agent did and why it stopped.
2. If a decision card is waiting, use **Approve**, **Reject**, **Edit** or **Escalate** in the thread. See [Decisions](/docs/ai/decisions).
3. Return to the list. The run leaves **Awaiting decision** once you answer.

## What to do next

Customer mail stays under [Communication](/docs/inbox/communication). Recurring wakes are planned on the [Agenda](/docs/ai/agenda).

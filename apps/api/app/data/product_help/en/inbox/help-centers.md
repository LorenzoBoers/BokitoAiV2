# Publish a help center

A help center is your public answers: pricing, policies, how your product works. It is separate from Bokito product help on `/docs`. Open **Settings**, then **Help center**.

## Create a collection

1. Open **Settings**, then **Help center**.
2. Under **Collections**, type a name (placeholder **e.g. Frequently asked questions**), optional **Description (optional)**, then **Add**.
3. Collections group the public articles. Internal notes stay in [Knowledge](/docs/ai/knowledge) and are not on this site. Use **Open Knowledge** when you want to write there first.

## Publish an article

![Help centers settings](/api/docs/assets/help-centers/publish.png)
*Published Knowledge docs appear here.*

1. Open **Knowledge** and select a document of kind **Docs**.
2. Use **Publish**. Bokito assigns a public slug.
3. Return to **Help center** to confirm the article is in a collection and live.

You can also **Upload** a file into the selected collection (**File name** and an https **File URL**, or a Knowledge upload path). **Delete collection** removes the collection and its documents. Publishing from Knowledge keeps the same source agents already read.

## Share it with customers

1. Choose **Copy public link** on Help center. The URL is `/help/{workspace}`.
2. Put it on your site, or choose **Install website chat** and turn on the **Help** module on the [Chat widget](/docs/inbox/widget).
3. Unpublish from Knowledge when the article should leave the public site.

## What to do next

Write the first articles in [Knowledge](/docs/ai/knowledge). Install the [widget](/docs/inbox/widget) if visitors should see Help next to chat.

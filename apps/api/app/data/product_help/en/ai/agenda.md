# How Agenda works

Agenda is when agents wake up. Schedule wakes, one-off tasks, recurring checks and incoming webhooks. This is not a meeting calendar — it is the run plan for your agents.

## Week and list

Week shows planned runs on each day. List is the same schedule as a feed. Today is highlighted so you can see what fires next.

## Automations

Triggers (cron, interval, heartbeat, webhook, one-off) live under Automations. Pause, edit or run now from there. Heartbeats check workspace docs on a timer.

## Attach a schedule

Use New to attach a schedule to an agent or a flow. Finished one-shots stay visible so you can see what already ran. On-demand chat runs belong in Activity, not here.

## What to do next

Open Agents to pick who should wake, or Projects if the work belongs to a shared goal.

# How Projects works

Group a product-owner agent, repository, threads and a token budget so work has a home instead of living only in chat.

## Read the cards

Each project shows its lead agent, repo status and remaining budget. Open it for orchestration, repository and recent runs.

## Keep talking in Communication

View threads deep-links into Communication filtered to that project. Agents and humans keep talking in Messages; the project is the spine.

## Cap spend on the project

Daily and hourly token budgets sit on the project so a single goal cannot consume the whole workspace cap.

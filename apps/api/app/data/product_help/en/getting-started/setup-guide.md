# Workspace setup guide

The quickstart gets you running; this guide gets you configured. Work through it top to bottom - later steps assume earlier ones.

## Workspace basics

Under **Settings, then Workspace**, set the workspace name, logo and language. Branding carries into the chat widget and outbound mail, so do this before anything customer-facing goes live.

## Invite the team

Add members under **Settings, then Members**. Owners and admins manage configuration and approve platform changes; members work threads. Invite the people who will answer customers first.

## Connect channels

Connect every mailbox the team answers from under **Settings, then Channels**. Add routing rules so mail lands with the right person or queue, and set signatures for outbound mail. Website chat and WhatsApp can wait until mail runs smoothly. See [Connect channels](/docs/inbox/channels).

## Load knowledge

Agents answer from **Knowledge**. Add the documents your team reaches for daily: pricing, FAQs, policies, product specifics. Publish customer-facing articles to the help center if you want the widget to show them. See [Knowledge](/docs/ai/knowledge).

## Configure agents

Review the default assistant under **Agents**: its role, instructions, tone and tools. Add specialized agents when one assistant is not enough - a support agent and a sales agent can run side by side. See [Agents](/docs/ai/agents).

## Set autonomy and guardrails

Pick the autonomy posture under **Settings, then Govern** and review what agents may do without approval. Start conservative: drafts and decision requests first, autonomous sending later, once you trust the output. See [Autonomy](/docs/govern/autonomy).

## Schedule recurring work

Put routine agent work on the **Agenda**: daily inbox sweeps, weekly summaries, follow-up runs. See [Agenda](/docs/ai/agenda).

## Done when

Mail flows in and gets answered, drafts are grounded in your knowledge, the team is in, and you know where approvals happen. Keep the [Cockpit](/docs/getting-started/cockpit) as your daily entry point.

# Communication in V2

**Communication** is the first page after login and the place where the company answers. Everything an agent does in a thread is a message in that thread, so you never have to look somewhere else to understand what happened.

## Pick what needs you

The list has five queues at the top. **Attention** is where you start the day.

1. Open **Communication**.
2. Choose a queue: **Attention** (waiting for a person), **Mine** (assigned to you), **Agents** (an agent owns the thread), **Waiting** (waiting for the customer) or **All**.
3. Narrow further with **Channel** and **Status**, or type in **Search conversations**.
4. Click a row to open the thread on the right. The header shows the channel, the status, the **Assignee** and the **Agent** that owns it.
5. Set **Assignee** to yourself to move the thread to **Mine**.

## Reply, note or ask the agent

The composer under the thread has three modes. The mode decides who sees what you write.

1. Choose **Reply** to write to the customer. AI-written replies on channels with disclosure on get the disclosure line automatically; yours do not.
2. Choose **Note** for an internal remark. Only colleagues and agents read notes.
3. Choose **Ask agent**, optionally type an instruction, and press **Run agent**. The agent reads the thread and acts within policy; the reply lands as a draft or is sent, depending on the posture.
4. Press **Ctrl Enter** to send.
5. If the banner **This reply waits for approval in the thread.** appears, the workspace policy asked for a decision. Approve it in the thread.

## Approve a decision inline

When an agent needs permission, the question appears as a card in the thread. Nobody has to open a separate queue.

1. Read the decision card: which tool, which arguments, why it asks.
2. Add an optional note.
3. Press **Approve** to let the action run now, or **Reject** to stop it.
4. The card shows **Approved** or **Rejected** and the result follows as a run message.
5. Open **Overview** for all open decisions across threads.

## Keep memory about a contact

The contact drawer holds what agents should remember about the person on the other side.

1. Click the contact name in the thread header.
2. Check **Email**, **Phone**, **Language** and **Verified**.
3. Write in **Memory** what matters next time, for example a preferred delivery day. It saves when you leave the field.
4. Scroll to **Conversations** for earlier threads with the same contact.

## See what one conversation cost

Every thread shows the model and channel cost it caused.

1. Open a thread and hover the cost badge in the header (**Model and channel cost for this conversation**).
2. Read the total, the model share and the channel share (for example WhatsApp template messages).
3. Rate an agent reply with **Good** or **Not good**. Feedback is recorded and used to score agents.
4. For the workspace total, open **Govern**, **Usage**.

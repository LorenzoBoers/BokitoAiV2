# Set autonomy posture

Autonomy posture is the workspace trust dial. It lives on Govern. Pick a preset, then override individual tools when needed.

## Manual

Agents research and draft. Lasting changes and outbound customer mail wait for a person. Use this while you are still learning how the workspace behaves.

## Assisted

Agents may apply low-risk actions and still ask for the rest. Inline decisions in Communication stay the day-to-day gate. Govern still holds structural drafts.

## Autonomous

Agents act within the tool allowances you set. Humans stay at the exception layer: rejected outcomes, locked tools, and anything that would change the platform.

## External sessions stay safe

Website visitors and other external sessions never auto-mutate the workspace, regardless of posture.

## What to do next

Start on Manual or Assisted. After a week of clean decisions, widen one tool category on Govern instead of jumping straight to Autonomous.

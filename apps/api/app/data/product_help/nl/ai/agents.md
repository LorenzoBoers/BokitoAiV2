# Zo werken Agents

Maak en configureer de AI-medewerkers van deze workspace. Chat met ze, geef ze tools en koppel ze aan projecten.

## Blader door de bibliotheek

Leads (product owners) staan boven workers. Elke kaart opent de agent zodat je instructies, model, tools en chat-toegang aanpast.

## Chat en planning

Chat opent een intern gesprek met die agent. Planning springt naar Agenda, gefilterd op dezelfde agent, zodat je een wake kunt koppelen.

## Voeg een agent toe

Admins voegen agents toe via Nieuwe agent. Leden praten met bestaande agents vanuit Communicatie. Tooltoegang en autonomie volgen Govern.

## Wat nu

Brief de agent in Kennis (persona, geheugen, skills) en zet daarna op Govern hoe autonoom die mag zijn.

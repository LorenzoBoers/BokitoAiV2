# Zo werken Projecten

Groepeer een product-owner-agent, repository, gesprekken en een tokenbudget zodat werk een thuis heeft in plaats van alleen in chat te leven.

## Lees de kaarten

Elk project toont de lead-agent, repostatus en resterend budget. Open het voor orchestratie, repository en recente runs.

## Blijf praten in Communicatie

Bekijk gesprekken springt naar Communicatie, gefilterd op dat project. Agents en mensen praten in Berichten; het project is de ruggengraat.

## Begrens kosten op het project

Dag- en uurbudgetten zitten op het project zodat één doel niet het hele workspace-plafond opeet.

## Wat nu

Hang een schema aan op Agenda, of zet de briefing die agents moeten volgen in Kennis.

# Zo werkt Kennis

Persona, geheugen, skills en checklists leven als workspace-docs. Agents lezen ze bij elke run en kunnen terugschrijven wat ze leren.

## Kies het juiste soort

Persona is toon en regels. Geheugen is langetermijnfeiten. Skills zijn procedures (SKILL.md-stijl). Heartbeat en daglog zijn door AI bijgehouden checklists.

## Publiceren voor klanten

Zet een doc op gepubliceerd om die op het publieke helpcentrum van deze tenant te tonen. Interne concepten blijven in de workspace. Dat helpcentrum is voor jullie klanten, niet voor Bokito-producthulp.

## Zoeken en schrijven

Zoeken is hybride (trefwoorden plus embeddings). Agents gebruiken dezelfde docs via tools. Wijzigingen hier zijn live bij de volgende run.

## Wat nu

Vul company.md tijdens de setup en voeg daarna een skill toe voor een procedure die je herhaalt. Chat met je assistant als je de eerste versie wilt laten schrijven.

Bokito Mobile dev

Production APK cannot hot reload.
If you open bokito-mobile.apk you get Failed to download remote update — that app looks for Expo OTA updates, not Metro.
Recommended: install the dev APK (dist/bokito-mobile-dev.apk), then run Metro with .\apps\mobile\scripts\dev-expo-phone.ps1 and open the dev app.

Expo Go (alternative)

Install dist/Expo-Go-55.0.7.apk (SDK 55). Play Store Expo Go is SDK 54 and fails.

Uninstall or ignore the production Bokito app while testing.

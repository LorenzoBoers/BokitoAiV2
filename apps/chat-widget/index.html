Bokito chat widget

Run npm install, npm run build, then npm run dev. Vite serves the demo page in your regular browser, with the built bundle at /bokito-chat.js.

  • Standalone demo Loads bokito-chat.js exactly like a real embed. Defaults to the local FastAPI; override via query params agent_slug, api_url, tenant, and auth_mode.

Example with a custom slug and host: chat-standalone.html?agent_slug=assistant&api_url=http://127.0.0.1:8000&tenant=my-tenant

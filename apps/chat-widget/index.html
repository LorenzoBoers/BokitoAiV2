Bokito chat-widget

Cursor Simple Browser laat bij http://localhost:8787 vaak een wit scherm zien (bekende webview-beperking). Start hier npm install en npm run dev: Vite opent je normale browser (Chrome/Edge) waar alles wel werkt, inclusief calls naar Xano.

Kies een pagina. De widget zelf staat op Standalone (embed zoals productie).

  • Standalone demo Laadt bokito-chat.js zoals een echte embed. Standaard tegen Xano; query agent_slug en api_url aanpasbaar.
  • API-testpagina Sequentiele tests en inline widget.
  • Legacy demo chat-module.js met lokale API-URL in het bestand.

Voorbeeld met eigen slug en host: chat-standalone.html?agent_slug=demo&api_url=https://…xano.io

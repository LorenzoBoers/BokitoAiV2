Bokito Chat Widget Demo

De chat widget staat rechtsonder in beeld. Klik op de blauwe knop om te beginnen.

Embed code

Voeg dit toe aan je website om de chatbot in te sluiten:

<script
  src="https://YOUR-XANO-URL/api:livechat/script/main"
  data-agent-slug="jouw-bot-slug"
  data-api-url="https://YOUR-XANO-URL"
></script>

Page Context Demo

Je kunt contextuele data meegeven aan de AI via window.chatContext:

window.chatContext = {
  customer_id: "12345",
  customer_name: "Jan de Vries",
  current_order: "ORD-67890",
  account_type: "premium"
};
